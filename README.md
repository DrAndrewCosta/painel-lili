
# Painel da Lili

Um painel colaborativo e em tempo real para conversar com a assistente Lili via texto.

## Como usar no Streamlit Cloud

1. Faça login em [streamlit.io/cloud](https://streamlit.io/cloud).
2. Crie um novo app e conecte ao seu repositório GitHub com este código.
3. Adicione sua chave da OpenAI em `Settings > Secrets`:

```
OPENAI_API_KEY = "sua-chave-aqui"
```
